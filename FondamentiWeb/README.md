# FondamentiWeb
repo fondamenti web


# Tecnologie da usare
Backend: Nodejs, Expressjs\
Frontend: React\
DataBase: MongoDB

Altre Info: 
Sessioni: Token JWT\
Autenticazione Sicura: OAuth, cookie, token\
Real-Time: Socket.IO\
RichiesteF: Axios, Fetch\
Navigazione:  React Router\
Componenti Layout: Material UI\
CSS: React Boostrap, Tailwind CSS\
Deployment: Vercel, Render, AWS, Netlify\
Architetture: microservizi, microfrontend, uso di container e strumenti come Kubernetes
